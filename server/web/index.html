Faraday relay · v1

This process cannot read your messages.

Faraday is an iOS messenger. This page is the operator view of the local ephemeral relay — the only backend in the MVP. Sealed blobs sit in RAM until the recipient device fetches them, then they are deleted. They are never written to disk. After 48 hours uncollected, they are discarded. This process has no decryption keys, display names, recovery phrases, or message bodies.

—mailboxes
—pending in RAM
0ciphertext on disk
48hour offline TTL
